# Kullanım ve kapsam notları

Bu UI paketi Delivery Driver için kullanıcı talebi doğrultusunda tasarlanmış görsel konseptlerden ve kaynak SVG simgelerinden oluşur.

- `07_Preview` tarayıcı kataloğu gerçek Unity yürütümü değildir; yerel dosyaların görsel önizlemesini sunar.
- 4 adet yüksek detaylı konsept, bu sohbet içindeki önceki üretilmiş çalışmaların kopyalarıdır.
- Özgün 2D vektör ikonları paket içinde tasarlanmıştır; bir üçüncü taraf ikon kütüphanesinden dosya aktarılmamıştır.
- Fonts packaged: none (Inter, sistemde kuruluysa kullanılır; aksi durumda proje fontu).
- Teslimat ekranlarında örnek veriler kullanılmıştır; lisans/metin ve grafikler oyun sahibinin doğrulamasına tabidir.
- Figma dosyası, Unity prefabı, atlas optimizasyonu ya da gerçek C# oyun mantığı pakette bulunmamaktadır. SVG ekran ve ikonlar Figma/Inkscape'e aktarılıp düzenlenebilir.
