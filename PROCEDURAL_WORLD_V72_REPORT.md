## Implementation
V7.1's shared height solver and balanced earthworks stages are preserved. New opt-in toggle (default on) V7.2 local optimization runs after the existing five stages and before the final prefab/park screening. Each stage is cloned, measured and either accepted or rolled back; stage history/checkpoints remain. The V7.2 stage guard retains land coverage, existing authored links, bridge count/connectivity, and rejects increases in sampled earthworks, radius flags, vertical severity or junction grade flags (small numeric tolerances). The old V7.1 pipeline remains selectable by disabling V7.2 local optimization. No use of saved local JSON as an automatic starting graph: Stage 0 regenerates the baseline from inputs. Prior settings/scene fingerprint changes invalidate the cache.

| Stage | Implementation |
|---|---|
| 5a Hotspot optimization | Find roads with sampled center/shoulder midpoint adjustments over preferred cap, try local height projection and tapered lateral offsets within a bounded window. Fixed endpoints, protected land, reservations, existing roads, grade/cross-section and network checks. |
| 5b Interior T-junction repair | Find detached components, test connectors to interior samples of retained land roads. Split only in preview graph, preserve original polyline exactly and prove both original endpoints are connected by the unchanged split chain. Bounded attempts, rejection counts. |
| 5c Local bend smoothing | Weighted local smoothing around worst horizontal radius, fixed endpoints. Reject terrain, radius or clearance regressions. Existing flags remain if no candidate. |
| 5d Vertical profile | Measure absolute slope change per mean neighboring horizontal sample spacing, approximate inverse vertical radius. Smooth local profile around worst interior flags, preserving endpoints. Report approximately straight-through junction transitions (not a built intersection surface); junction flags and bridge/authored vertical flags are diagnostic, not automatically repaired. |
| 5e Alternative bridge gates | Try existing generated dead-end nodes near opposing shores as alternative gates, fixed existing node elevations, straight/curved land approaches, separation scoring, protected/existing-road clearance, grade, radius and connection checks. Existing bridge replaced only if stage guard approves; existing land graph unchanged. Authored coastal corridor count remains an audit; no permission to traverse Kizilay or build on existing roads. Actual new authored-road corridor integration still deferred. |
| 6 Urban validation | Re-screen measured prefab footprints, approach slopes and parks; try extra sampled perimeter entrances up to 65 m from a road, avoid proposed lots. |
| Final diagnostics | Hotspots with XYZ positions, vertical flag overlay, 7-point cross sections (outer shoulder, sidewalk edges, asphalt edges, center), proposed vs original height, sparse 4m overlap-cell warning, shoulder slope / retaining-wall candidate warnings, protected/existing-road and lot shoulder samples. Inspector and focus buttons. Snapshot round-trip. |

Virtual terrain is a **sampled cross-section visualization** of land roads, not a continuous heightmap, earthwork volume calculation, actual retaining-wall placement or collider validation. Nominal spacing defaults to 20 m and may increase with total network length; at least one section per sufficiently sampled road means section count may exceed the nominal 12000 target. 4m shared sample cells are conservative approximate conflicts, not exact polygon intersections; both false positives and missed overlap are possible. Shoulder points use flat road/sidewalk target minus 0.12 m and linear blend to original ground. Bridge decks and authored paths are not flattened by this analysis. Lots and protected sample counts are diagnostics, not independent unique parcels. Final bake requires V7.3 continuous terrain/corridor and mesh checks.

Short stubs deliberately remain in the graph pending access-value assessment; Istanbul neighborhood redesign is deferred to a separate design experiment. No road removals for cosmetic improvement. Preferred grading cap is a target, not a replacement for the hard terrain budget. Mandatory preview criteria additionally flag vertical/junction violations, peak above preferred cap and virtual terrain warnings. No score can enable Generate, even with all checks passed.
