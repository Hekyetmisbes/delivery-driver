===========================================
QUESTMANAGER KURULUM REHBERİ
===========================================

QuestManager olmadan görev sistemi çalışmaz!
Log'da görünen hata:
"[DeliveryManager] QuestManager not found! Quest will not be created."

===========================================
ADIM 1: QuestManager GameObject Oluştur
===========================================

1. Unity Editor'de Hierarchy paneline gidin
2. Sağ tıklayın → Create Empty
3. Adını "QuestManager" yapın

===========================================
ADIM 2: QuestManager Script Ekleyin
===========================================

1. Az önce oluşturduğunuz "QuestManager" GameObject'ini seçin
2. Inspector'da "Add Component" butonuna tıklayın
3. "QuestManager" yazın ve scripti ekleyin

===========================================
ADIM 3: UI Sistemini Kurun
===========================================

1. Hierarchy'de sağ tıklayın → Create Empty
2. Adını "QuestUISetupHelper" yapın
3. Inspector'da "Add Component" → "QuestUISetup" scripti ekleyin
4. Play tuşuna basın (▶)
5. Console'da "Quest UI setup complete!" mesajını bekleyin
6. Play'i durdurun (■)
7. "QuestUISetupHelper" GameObject'ini silin (artık gerekli değil)

===========================================
ADIM 4: Sahneyi Kaydedin
===========================================

Ctrl+S veya File → Save yapın

===========================================
SONUÇ
===========================================

Artık:
✓ QuestManager sahnede olacak
✓ TAB tuşu çalışacak (görev listesi açılacak)
✓ Görev tamamladığınızda "GÖREV TAMAMLANDI" ekranı çıkacak
✓ Aktif görev bilgileri sağ üstte görünecek

===========================================
TEST
===========================================

Play tuşuna basıp şunları deneyin:
1. TAB tuşuna basın → Görev listesi açılmalı/kapanmalı
2. Paketi alın ve teslim edin
3. Teslim edince yeşil tamamlama ekranı çıkmalı

===========================================
SORUN YAŞARSANIZ
===========================================

Console'da (Window → General → Console) hata var mı kontrol edin
Hata mesajlarını paylaşın, yardımcı olayım.
